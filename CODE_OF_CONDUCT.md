# Community guidelines

[English](#english) · [中文](#中文)

## English

Be helpful and respectful. Critique designs and evidence, not people. Welcome newcomers, explain assumptions, and accept corrections. Harassment, discrimination, threats, personal attacks and publishing someone else's private information are not acceptable.

Maintainers may edit or remove inappropriate content, close disruptive threads or limit participation. Use available GitHub moderation and reporting channels for abuse; do not repeat private details in a public Issue. These guidelines apply to this repository's Issues, pull requests and discussions.

## 中文

**交流约定**

请友善、尊重地交流。讨论设计和证据本身，欢迎刚开始制作的人，解释前提，并接受更正。不接受骚扰、歧视、威胁、人身攻击或公开他人隐私。

维护者可以处理不当内容、关闭扰乱讨论的帖子或限制参与。遇到骚扰可使用 GitHub 的举报和管理功能，勿在公开 Issue 中重复隐私信息。本约定适用于仓库的 Issue、PR 和讨论。
