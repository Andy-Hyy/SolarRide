# V6.5 source package

[English](#english) · [中文](#中文)

## English

SolarRide combines a bicycle bag with a wireless turn-signal rear strip, an IMU-triggered braking indication and solar-assisted battery power. This source package includes V6.5 firmware, local pairing setup, PCB and STEP enclosure sources, macOS BLE tools, host checks and English/Chinese guides.

The existing device has completed USB programming, remote left/right/stop checks, and a mounted brake-warning check after the threshold was recalibrated for the installed tilt. Battery runtime and solar charging input have not been measured. False-flash rates, behavior on different roads, and a complete BLE update/recovery are still open. Only the screw-fastened enclosure has been printed. The power module chain and terminal relationships are documented; connector pin order, protection/charging measurements and mechanical replication details still need checking.

Build your own firmware with a private local PIN. Existing device binaries are not included. Software, hardware and documentation use MIT, CERN-OHL-P-2.0 and CC BY 4.0 respectively, with third-party terms retained separately.
