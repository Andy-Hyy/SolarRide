# Useful next improvements

[中文](../zh-CN/roadmap.md) · [Home](../../README.md)


The following are open work items, not implemented features or delivery promises.

- Check connector pin order, charger/protection measurements and exact mechanical details; keep the confirmed power wiring and fabrication sources current.
- Measure charging current and battery behavior under defined light and load conditions; measure runtime rather than estimating it from nominal panel wattage.
- Record labeled rides for false flashes, startup recovery and vibration. The existing mounted brake check is not that record.
- Verify actual BLE transfers, pairing, restarts, interrupted updates and bootloader-dependent recovery. Improve the Mac tools' English interface and explicit device selection.
- Physically print and fit the sliding-frame enclosure; document print settings, screws, weather protection and cable exits.
- Consider a simpler configurable steady braking pattern, mount calibration tooling and tests for additional hardware variants.
- Consider persistent ride logging only after deciding storage format, timing and flash-write effects.

Please describe a concrete change and its checks in an Issue before expanding scope.
