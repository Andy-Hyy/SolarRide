# 故障排查

[English](../en/troubleshooting.md) · [首页](../../README.zh-CN.md)

| 现象 | 检查 |
| --- | --- |
| 缺少 `OTAPairing.h` | 复制示例文件，填入配对码，并删除 `#error` |
| 红色闪烁 | 5 V、共地、GPIO4/5、地址 0x68 |
| 黄色持续 | 保持自行车直立静止 |
| 紫色 | I²C 与供电。表示传感器读取失败 |
| 左右相反 | 以骑行者视角核对。左为 GPIO3，右为 GPIO6 |
| 遥控输入保持有效 | 无按键时接收器应为低电平。停止为 GPIO10 |
| 颜色不正确 | `DIN`、GRB 顺序、共地，以及灯带点亮时的 5 V |
| 刹车提示不解除 | 安装向量、车包晃动、`forward_filtered` |
| 无蓝牙数据 | 仅连接本机，并等待完整的一行 |
| 升级被拒绝 | 使用 `.ino.bin`。自行车静止，校准已完成，配对码位于 `OTAPairing.h` |
| 传输完成但固件未更换 | 确认 USB 可用，以及新镜像是否已经启动 |
| 灯带变亮时复位 | 在灯带点亮时测量 5 V |
