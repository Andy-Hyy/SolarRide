| 看到的 | 看哪里 |
| --- | --- |
| 没有 `OTAPairing.h` | 复制示例，填配对码，删 `#error` |
| 红灯闪 | 5 V、地、GPIO4/5、地址 0x68 |
| 一直黄 | 车停稳、扶直 |
| 紫 | I²C 和供电。这次读取失败了 |
| 左右反了 | 从坐垫上看。左 GPIO3，右 GPIO6 |
| 某个遥控输入一直有效 | 没按键时应为低电平。停止是 GPIO10 |
| 颜色不对 | `DIN`、GRB、地、灯亮时的 5 V |
| 刹车灯不灭 | 车头向量、车包晃动、`forward_filtered` |
| 蓝牙没有数据 | 只连这一台，等一整行 |
| 升级被拒 | `.ino.bin`，车停着，校准完成，配对码在 `OTAPairing.h` |
| 传完了，板子没变 | USB，以及有没有用新程序启动 |
| 灯一亮就复位 | 灯带亮着时量 5 V |
