# 排障

[English](../en/troubleshooting.md) · [首页](../../README.zh-CN.md)


| 现象 | 检查方法 |
| --- | --- |
| 编译找不到 `OTAPairing.h` | 运行本地配置工具，或配置示例头文件 |
| MPU 启动失败、红灯闪烁 | 检查供电、共地、GPIO4/5、地址 0x68 和模块连接 |
| 黄灯持续 | 保持车身直立静止，检查振动、传感器数据和校准原因码 |
| 紫灯 | 检查 I²C、读取错误和供电；紫灯不表示校准成功 |
| 左右反向 | 检查骑行者视角、灯带顺序和遥控映射；V6.5 为左 GPIO3、右 GPIO6 |
| 遥控输入一直有效 | 检查接收模块工作方式、空闲电平和高电平有效映射；停止为 GPIO10 |
| LED 颜色或显示错误 | 检查 `DIN`、GRB 顺序、数据电平、共地和带载供电 |
| 刹车提示持续 | 停车等待稳定基准恢复，检查方向向量、车包晃动和 `forward_filtered`；不能据此认为道路问题已解决 |
| BLE 没有数据 | 允许 Mac 蓝牙访问，关闭其他客户端，只给目标设备通电，等待完整行 |
| 升级被拒绝 | 使用带 OTA 标记的 C3 应用镜像，检查停车静止条件、OTA 分区、配对与协议 |
| 升级未确认成功 | 保留 USB 恢复，检查身份与启动状态，不能只凭传输完成推断成功 |
| LED 变亮时复位 | 测电压跌落与接线，检查稳压容量、电池状态和导线 |

反馈时请提供固件/核心版本、实物模块、安装方式、复现步骤及去除隐私后的观察，不附私有配对文件或带设备标识的原始日志。
