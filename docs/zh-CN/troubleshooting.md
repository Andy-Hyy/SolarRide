# 排障

[English](../en/troubleshooting.md) · [首页](../../README.md)


| 现象 | 检查方法 |
| --- | --- |
| 编译找不到 `OTAPairing.h` | 把 `OTAPairing.example.h` 复制成 `OTAPairing.h`，填上配对码，删掉 `#error` |
| MPU 启动失败、红灯闪烁 | 检查供电、共地、GPIO4/5、地址 0x68 和模块连接 |
| 黄灯持续 | 保持车身直立静止，检查振动、传感器数据和校准原因码 |
| 紫灯 | 查 I²C、读数和供电。紫灯是传感器读数有问题 |
| 左右反向 | 从坐垫上看，再看灯带方向。V6.5 是左 GPIO3、右 GPIO6 |
| 遥控输入一直有效 | 没按键时接收器应该是低电平。停止是 GPIO10 |
| LED 颜色或显示错误 | 检查 `DIN`、GRB 顺序、数据电平、共地和带载供电 |
| 刹车提示持续 | 停下来等。看安装方向、车包是不是在晃，以及 `forward_filtered` |
| BLE 没有数据 | 允许 Mac 蓝牙访问，关闭其他客户端，只给目标设备通电，等待完整行 |
| 升级被拒绝 | 发这个 ESP32-C3 程序编译出来的 `.ino.bin`。车停着，校准完成，配对码用 `OTAPairing.h` 里的 |
| 升级未确认成功 | USB 口留着。传完还要看板子是不是用新程序启动了 |
| LED 变亮时复位 | 灯亮的时候量电压。看升压板、电池和线 |
