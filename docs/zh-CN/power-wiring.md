# 供电接线

[English](../en/power-wiring.md) · [首页](../../README.md) · [硬件](hardware.md)

以下为维护者确认的现有实物连接结构，表示端子关系，不表示接头的具体针脚顺序，也不是对充电行为的独立验证。

![供电连接](../assets/power-wiring.svg)

## 端子连接表

| 来源 | 接到 | 连接关系 |
| --- | --- | --- |
| 两块光伏板正极/负极 | CN3163 SOLAR+ / SOLAR− | 两块 1 W/6 V 光伏板同极并联 |
| CN3163 BAT+ / BAT− | 锂电池正极/负极 | 太阳能充电板的电池端接电池 |
| 4056-TP 电池端正极/负极 | 同一锂电池正极/负极 | 两块充电管理板共接电池端 |
| USB-C 电源 | 4056-TP Type-C 输入 | 太阳能不能有效充电时，通过 USB 给锂电池充电 |
| 4056-TP OUT+ / OUT− | XR2981 IN+ / IN− | 负载供电取自充电管理板输出 |
| XR2981 OUT+ / OUT− | ESP32 载板 5 V / 电源回流端 | 固定 5 V 稳压供电，接入前测实际电压 |

载板按已有设计把 5 V 电源分配给主灯带和状态灯。升压输入不记作直接连接电池；4056-TP 输出口也不记作固定 5 V，5 V 由 XR2981 产生。

不要仅因都被叫作“地”，就把电池负极与保护输出负极直接跨接；需按保护结构保留这里的端子路径。下游信号模块共用控制侧电源回流端，接头颜色和外形不证明极性。

## 充电方式与核验

太阳能不足时，Type-C 作为备用充电输入。太阳能/USB 同时输入、实际充电电流、保护阈值、反向电流和温升尚未测量，本说明不据此确认双输入同时工作的安全性或续航。

先断开负载确认端子极性和模块型号，连接 ESP32 前测 XR2981 输出，再以实际灯效检查压降和温升。根据模块及电池资料确认限流适合 1200 mAh 电池。更换成普通裸充电板时，开关、保护与输出行为可能不同，不能只按名字替换。

PCB 文件含外部连接和安装位置，完整充电链还依赖模块接线。应将本表和硬件源文件一起阅读，不能只依据较早原理图。
