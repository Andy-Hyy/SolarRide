# 值得继续做的改进

[English](../en/roadmap.md) · [首页](../../README.md)


下面是尚待完成的工作，不是已实现功能或交付承诺。

- 检查具体接头针脚、充电/保护测量与机械细节，维护已确认供电关系和生产源文件。
- 在明确光照与负载下测量充电电流和电池表现，测续航，不从标称太阳能功率直接推算。
- 用有动作标注的骑行记录检查持续误闪、移动开机后的恢复和振动敏感性。已有的一次装车刹车检查不是这份记录。
- 实测 BLE 传输、配对、重启、升级中断及依赖引导程序的恢复；补充 Mac 工具英文界面和明确设备选择。
- 打印、适配抽拉外框，记录打印参数、螺丝、防水处理和出线方式。
- 考虑可配置的常亮刹车灯效、方向校准工具和其他硬件版本核验。
- 如增加持久骑行日志，先确认格式、时序和写闪存的影响。

扩展范围前，请在 Issue 中说明具体修改和核验方法。
