# 方向

[English](../en/calibration.md) · [首页](../../README.zh-CN.md)

上电后，固件估计重力与陀螺仪零偏，不估计车头方向。`BrakeDetector.h` 中的前向向量对应当前控制盒的安装姿态：

```cpp
const Vec3 forward={-0.5883380f,-0.7899954f,0.1725274f};
```

刹车提示使用 35 ms 滤波。前向加速度低于 −0.70 m/s² 并持续 150 ms 后触发，随后至少保持 700 ms。

安装方式改变后需要重新测定。自行车直立静止时记录 `g0`。略微抬起前轮并记录 `g1`。取 `v = g1/|g1|`，再计算 `p = v - g0 * dot(v,g0)/dot(g0,g0)`，并对 `p` 归一化。烧录后，向前刹停时 `forward_filtered` 应为负值。若符号相反，将向量取反。

上电后保持自行车直立静止约两秒，直至状态灯变为青色（`ready=1`）。
