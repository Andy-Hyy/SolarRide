# 安装方向与校准

[English](../en/calibration.md) · [首页](../../README.md)


## 两种不同的基准

开机时固件学习静止重力基准和陀螺仪偏置，**不会**自动学习自行车的车头方向。`BrakeDetector.h` 内有一个对应现有安装的固定车头向量：

```cpp
const Vec3 forward={-0.5883380f,-0.7899954f,0.1725274f};
```

如果你的 MPU6050 朝向不同，不能照搬这个向量。这是我这块盒子装在车上的方向，不是每台都能用的数。

## 取得自己的方向

1. 将传感器和车包固定在最终位置，保持车身直立、静止，记录几秒稳定加速度均值 `g0`。
2. 在受控静止环境中稳固支撑车身，适度抬起前轮，车身保持直立，记录稳定均值 `g1`。放下前轮并确认原基准恢复。
3. 令 `v = g1/|g1|`，去掉其在原重力方向上的分量：`p = v - g0 * dot(v,g0)/dot(g0,g0)`；归一化 `p` 得到候选车头方向。若 `|p|` 很小，说明抬起幅度不足或测量噪声过大。
4. 把候选向量写入 `BrakeDetector.h`，重新编译并通过 USB 烧录。在有明确动作标注的向前推车刹停中，确认刹停时 `forward_filtered` 为**负值**并低于负阈值。若符号错误，将向量反向后复测。
5. 检查静止、几次轻缓和稍明显的推车刹停，以及提示自行解除；保存安装和校准说明。

每次开机尽量让车身直立、静止约两秒，再等待状态灯成为青色或 `ready=1`。晃动会推迟校准，检测器会等待合适的静止窗口。明显改变传感器朝向后，应重新校准车头向量。小角度放置的主机测试不能证明松散摆动车包或任意安装方向的表现。
