# 安装方向与校准

[English](../en/calibration.md) · [首页](../../README.md)


## 两种不同的基准

开机时固件学习静止重力基准和陀螺仪偏置，**不会**自动学习自行车的车头方向。`BrakeDetector.h` 内有一个对应现有安装的固定车头向量：

```cpp
const Vec3 forward={-0.5883380f,-0.7899954f,0.1725274f};
```

这个向量是我这块盒子装在车上的方向。MPU6050 朝向不一样的话，要重新量。

## 取得自己的方向

1. 将传感器和车包固定在最终位置，保持车身直立、静止，记录几秒稳定加速度均值 `g0`。
2. 车身扶直，前轮抬起一点，记下另一个稳定的平均值 `g1`。放下前轮，看第一次的读数回来没有。
3. 令 `v = g1/|g1|`，去掉其在原重力方向上的分量：`p = v - g0 * dot(v,g0)/dot(g0,g0)`；归一化 `p` 得到候选车头方向。若 `|p|` 很小，说明抬起幅度不足或测量噪声过大。
4. 把这个向量写进 `BrakeDetector.h`，重新编译，用 USB 烧录。向前推一下再停住。刹停时 `forward_filtered` 应该是**负数**，并且低于那个负阈值。符号反了就把向量反过来再试。
5. 然后我试静止、几次轻一点的停、几次重一点的停，看提示自己灭掉。

每次开机我让车直立、停大约两秒，再等状态灯变成青色，或者 `ready=1`。车在动，校准就等着。传感器转了方向，我就重新量车头向量。
