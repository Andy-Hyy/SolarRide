# 方向

[English](../en/calibration.md) · [首页](../../README.md)

开机时学的是重力和陀螺零偏，不学车头朝哪。`BrakeDetector.h` 里的车头向量是我这块盒子装在车上的方向：

```cpp
const Vec3 forward={-0.5883380f,-0.7899954f,0.1725274f};
```

刹车灯：35 ms 滤波，低于 −0.70 m/s² 并持续 150 ms，然后至少保持 700 ms。

换一种装法就要重测。车直立静止时记下 `g0`。前轮抬起一点，记下 `g1`。`v = g1/|g1|`，`p = v - g0 * dot(v,g0)/dot(g0,g0)`，再把 `p` 归一化。烧录后向前推再停住，`forward_filtered` 应为负。符号反了就把向量反过来。

开机时车直立停大约两秒，状态灯变青（`ready=1`）。
