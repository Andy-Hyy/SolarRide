# 使用灯光

[English](../en/operation.md) · [首页](../../README.zh-CN.md)


1. 检查车包、电池和线缆是否牢固。接通电源后保持车身直立、静止，等校准完成。
2. 骑行前从骑行者视角测试左转和右转。停止功能返回常规红灯模式，不会制动自行车，也不会切断电源。
3. 检测到刹车状态时优先显示刹车灯效，结束后恢复所选模式。遥控器没有连接机械刹车。
4. 出现异常时，在安全位置停车，查看状态灯与遥测。处理接线前先关闭电源。
5. 升级时停车操作，保持供电稳定并保留 USB 恢复条件。

## 状态灯

| 状态 | 状态灯 | 含义 |
| --- | --- | --- |
| 启动或校准 | 微黄 | 等待静止基准 |
| 正常就绪 | 微青 | 检测器就绪，常规模式 |
| 转向 | 黄灯闪烁 | 已选择左或右转 |
| 刹车状态 | 红 | 当前刹车提示有效 |
| 运行中传感器无效 | 紫 | 读取或合理性检查失败 |
| MPU 初始化失败 | 红灯闪烁 | 固件无法初始化传感器 |
| OTA 维护 | 蓝色明暗变化 | 更新期间暂停行车灯效 |

尾部刹车灯每 50 ms 切换一次明灭，约每秒 10 次完整闪烁。时间值可在主程序修改，但需要重新编译并实际观察灯效。骑行中不要调参或操作维护工具。

当前固件未实现电量百分比、车载持久骑行日志、手机转向控制或自动太阳能能量管理；充电由所装硬件模块处理。
