# 灯效

[English](../en/operation.md) · [首页](../../README.zh-CN.md)

| 状态 | 状态灯 |
| --- | --- |
| 校准中 | 暗黄 |
| 就绪 | 暗青 |
| 转向 | 琥珀色闪烁 |
| 刹车 | 红 |
| 传感器读取失败 | 紫 |
| MPU 初始化失败 | 红色闪烁 |
| 蓝牙升级 | 蓝色渐变 |

尾灯为 10 颗。常规灯效中，两颗红色灯珠自中心向两侧移动。左转与右转分别使用相反方向的琥珀色流水灯。遥控器的停止键恢复常规红灯。刹车提示优先于当前灯效，结束后恢复先前模式。刹车灯效每 50 ms 切换一次。
