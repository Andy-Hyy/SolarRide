# 使用灯光

[English](../en/operation.md) · [首页](../../README.md)


1. 我看车包、电池和线。然后开机，把车扶稳，等到状态灯变成青色。
2. 上车前我从坐垫上看过左转和右转。遥控器上的停止只是把灯切回平时的红灯。
3. 刹车提示亮着的时候盖过转向灯，结束后回到刚才的模式。遥控器只改灯。
4. 灯看起来不对，我就停下，看状态灯，碰线之前先断电。
5. 升级的时候车是停着的，USB 口留着。

## 状态灯

| 状态 | 状态灯 | 含义 |
| --- | --- | --- |
| 启动或校准 | 微黄 | 等待静止基准 |
| 正常就绪 | 微青 | 检测器就绪，常规模式 |
| 转向 | 黄灯闪烁 | 已选择左或右转 |
| 刹车状态 | 红 | 当前刹车提示有效 |
| 传感器读数有问题 | 紫 | 这次读取失败了 |
| MPU 初始化失败 | 红灯闪烁 | 固件无法初始化传感器 |
| OTA 维护 | 蓝色明暗变化 | 更新期间暂停行车灯效 |

尾部刹车灯每 50 ms 亮灭一次。要改这个时间，我改程序再烧录。骑的时候不改。
