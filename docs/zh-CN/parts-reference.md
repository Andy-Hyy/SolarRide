# 我用的零件

[English](../en/parts-reference.md) · [首页](../../README.md) · [硬件](hardware.md) · [供电接线](power-wiring.md)

| 零件 | 我买的 |
| --- | --- |
| ESP32-C3 开发板 | CORE-ESP32 外形，排针焊好，4 MB 闪存。Arduino 目标是 AirM2M CORE ESP32C3 |
| GY-521 MPU6050 | 排针向下焊。程序用 I²C 地址 0x68 |
| KS-59E 接收器和遥控器 | 433 MHz。接收器把左转、右转、停止输出成高电平。商品页写接收器 5 V 供电 |
| CN3163 太阳能充电板 | 蓝色接头板。商品页写输入 DC 4.4–6 V。两块光伏板并联进 SOLAR，BAT 接电池 |
| 4056-TP Type-C 充电板 | 带电池口、输出口、开关和状态灯。商品页写 1 A、3.7 V / 4.2 V。Type-C 给电池充电，OUT 接到 XR2981 |
| XR2981 升压板 | 固定 5 V 那一款，电感标着 “2R2”。IN 接 4056-TP 的输出，OUT 给 ESP32 板供电 |
| 103040 电池 | 商品页：3.7 V、1200 mAh、4.44 Wh，充电到 4.2 V，大约 10 × 30 × 40 mm |
| 柔性太阳能板 | 两块，商品页写每块 1 W / 6 V，并联 |
| WS2812B 灯带 | 5 V、黑板、滴胶、1 米、144 颗/米。我剪了 10 颗 |
| WS2812D-F5 状态灯 | 一颗 5 mm 直插灯。图上是 1 DOUT、2 VDD、3 GND、4 DIN。我接 DIN、VDD、GND |
| 车架包 | 商品页有 1.5 L 和 2.7 L |
| 座管支架 | F321 这一类夹具。座管尺寸是我在车上量的 |

EasyEDA 工程里另一页 PCB 上的零件，我没有装到这块做好的板上。
